VEAS NETWORK
Vue d'Ensemble, Analyse et Sécurité Réseau
Outil local d'observabilité réseau. Il découvre les appareils du réseau local, mesure le trafic IP et signale les schémas soutenus de scan de ports TCP dans un tableau de bord web.
Python Flask Scapy arp-scan Socket.IO REST API Docker Observabilité IDS
github.com/5yn0r/VEAS_NETWORK
// Fonctionnalités
  • Découverte des appareils visibles sur le LAN avec arp-scan
  • Capture du trafic IP avec Scapy : volumes upload / download par IP locale
  • Historique borné de métadonnées de paquets (sans contenu), filtrable par IP, protocole, sens et port
  • Alerte de scan de ports uniquement après un nombre configurable de ports TCP SYN distincts dans une fenêtre de temps
  • Instantanés REST et mises à jour en direct via Socket.IO
À utiliser uniquement sur des réseaux que vous possédez ou êtes autorisé à administrer. Volontairement en mémoire : un redémarrage efface appareils, trafic et alertes.
